本轮兼容性冒烟通过，**全面性能验收尚未通过**。新候选完成 2 对 AB/BA、28 次串行运行和 200 个阶段样本，严格评估 `smoke-valid`，100 项指标完整，输入、产物、sourcemap 和采集的告警零差异。所有 28 次 prepare 成功。两对样本不构成稳定收益或稳定回退的判定。

## 变更与边界

同一次入口加载中，原生布局的入口登记、依赖收集和输出共用一次文件发现。每次 `loadEntry` 创建独立 resolver，不把结果保存在跨轮 layout plan 中；平台与原始路径分别作为身份，失败保留原错误并允许重试。共享的仅是资产路径，源码仍通过 `readCompilerInput` 消费当前快照，WXML 扫描、依赖发布和 Vite/Rolldown 输出保持原有阶段。

本次冻结产物还包含之前采样后恢复的 SFC 同内容 mtime 校验。当前工作树与冻结候选的 1,274 个相关生产源码、bin、dist 和包清单逐文件哈希一致；冻结后的缓存契约测试与 workflow 诊断修改不属于性能实现。完整冻结身份以 provenance 中的原始 SHA-256 为准。

基线为本 PR 早期 `419f49d914142a591d5e109fcb3010feed66ab19`，不是 main；双方 native 关闭。下表是累积 JS 架构改动的差异，既不是 Rust 收益，也不是布局复用的单独消融结果。沿用相同冻结依赖、120 ms watcher polling、25 ms output polling、保存/恢复、GC 和缓存隔离策略；本轮关闭 profile，没有采用此前插桩诊断的驱动时机。
