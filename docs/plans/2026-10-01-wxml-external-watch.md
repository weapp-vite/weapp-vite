# WXML 根外依赖监听所有权

WXML 转换通过 `addWatchFile` 登记的输入未必属于 Vite 模块图，也可能位于项目根目录之外。仅向共享文件监听器添加单个根外文件，在 Chokidar 5 同时监听项目根和外部文件时，文件删除后会失去重新创建通知。纯 Chokidar 对照无需框架即可复现。

项目内输入仍使用 Vite 的监听器。项目外输入由开发会话持有单个浅层父目录监听器，仅接受当前依赖集合中的文件事件；保留用户的 ignored、轮询等显式选项，不递归扫描根外目录。共享 Vite 通知对这些路径不再触发重复失效。父目录句柄保留至会话关闭以支持删除后的恢复，已释放输入的事件被精确过滤。

附着宿主与独立 provider 共用同一绑定器。Vite middleware 模式没有 HTTP server，其释放依赖插件 `closeBundle`；普通宿主关闭及原生 watcher 关闭同样使用幂等 disposer，不释放其他 listener。

回归包含原生文件修改、删除、重建，运行中登记已存在兄弟文件后的首次保存，middleware 关闭与重复关闭。runtime suite 对项目内和项目外两种规则布局分别执行自然构建失败/恢复，再以同一 suite 的唯一宿主切换原生及 Vue 页面，验证最终模板属性与点击事件。它证明恢复产物的 runtime 语义，不宣称页面 CSS/HMR 已通过。

诊断同时把未加命名空间的 Consola `ERROR`/`WARN` 终端前缀规范为 CI 的方括号前缀，保持严重度、正文、动作作用域及错误数量不变。预期构建错误不替换 runtime 断言。
