# CLI 项目恢复边界

`wv open` 的索引恢复、强制重开以及截图超时重试曾调用没有项目定位的 `close`；连接失败时还可能执行整个 IDE 的 `quit`。显式 `wv close` 失败则通过 AppleScript 或进程匹配退出整个宿主。项目路径和 CLI 安装路径都不能证明进程所有权。

本次将打开恢复和显式关闭分离：前者只重试目标项目连接，后者只保留原生 CLI close 及正常登录重试，失败返回 false。截图重试保留一次重试上限，由既有会话生命周期释放失败连接，不在重试层再次按项目键清理或执行全局 close。现有公开签名不变，帮助与随包文档同步。

回归先在纯 mock 中复现 13 项失败，涵盖不健康/不可达会话、索引恢复、三系统关闭失败与截图协议/导航/请求超时；修改后 61 项通过。额外四个回归先证明截图重试层仍按项目键重复清理，删除后不再影响已由其他调用替换的连接。所有宿主命令均为 mock，没有为复现退出用户窗口。

相关 7 个测试文件共 141 项通过，两个包 typecheck、公开类型、构建及网站构建通过；构建后的 open/build/dev/close 帮助入口通过。没有新增公开类型签名。

真实最新稳定版共享宿主验收仍待完成：同时保留手动项目和另一项目，验证目标打开、超时恢复、截图和显式关闭失败后两者仍可操作。当前 Computer Use 返回 Mac locked，未绕过锁屏，单测不能替代最终验收。
