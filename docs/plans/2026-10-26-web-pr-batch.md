## 验证与交付

每条 PR 完成路径 lint、所属包 typecheck、公开类型测试和定向单测，重建受影响包后再验证下游。浏览器测试执行实际编译结果；本机 Web、headless、HMR 和 IDE E2E 串行运行。共享增量验证 CSS 恢复、配置重启与关闭、进程身份、simulator registry 和性能采集契约，保留冻结性能证据。

每轮独立核验 PR、head/base、merge SHA、run 与 attempt 后批准原生 CI，核对全部适用矩阵、聚合及 statuses。按 #1257 → #1256 → #1255 → #1245 → #1246 → #1247 → #1254 → #1258 顺序合并；每次合并前同步最新 main 并完成本轮检查。

真实 IDE 的既有宿主初始化阻塞单独记录。只有出现新诊断或环境修复证据后继续；必要 runtime 验收无法完成时保留待验收状态。正式全量 IDE 验收在合并后的干净同步 main 工作树执行，不将局部或替代覆盖记为全量通过。
