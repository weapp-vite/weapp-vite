# Issues 1330、1331、1332 同批修复

目标是在一个 PR 中修复三个作者复现，并通过真实 DevTools runtime 验收。

## 根因与方案

- Issue 1330：WXML formatter 只允许自闭合子标签内联，并提前删除空白 token，导致嵌套 text 被插入换行与缩进。保留 text 和直属文本混排子树的原始 token；纯结构容器继续缩进。测试覆盖嵌套、空白、注释和幂等性。
- Issue 1331：编译器只可静态提取字面量初值；computed 和工厂初值需要 setup。原生模板在 setup 首快照前已创建子组件，向 String 属性交付空值。对于 script setup 的动态组件属性，编译器增加首帧条件，运行时在完成 setup 后将就绪标记与状态放入同一快照。模块与具名模板仍在顶层，已有 if/else/for 结构保留。静态组件和纯文本不新增等待。内部标记位于共享 constants 包，并绕过业务 setData 字段筛选；不提前执行用户函数，不重复执行 setup，不修改显式 null 的语义。异步导航 guard 完成前不打开屏障，abort 保持关闭。
- Issue 1332：入口扫描读取了外部 setup 内容，却以宿主 Vue 文件为 importer 解析其组件 import。复用当前解析流程记录的外部块真实身份，覆盖相对、alias 和包路径，扫描缓存仍由宿主入口拥有。

## 真实宿主与 headless 对齐

真实 DevTools 观察到 String 属性显式空值警告，headless 原先静默归一化。mpcore 增加同样的会话级诊断，区分未传属性与显式空绑定，避免同一渲染重复报告；包含 Node、browser session 和 Chromium E2E。

作者原始业务源码及配置复制到 `e2e-apps/github-issues/fixtures/issue-1330-*`、`issue-1331-*`、`issue-1332-*`。只固定仓库通用 AppID，并补页面启动条件。临时宿主通过公共 CLI 构建，检查产物文件与注册路径；每个 fixture 只启动一次 automator，切页使用 reLaunch。

## 验证与范围

按最小单测、包级 typecheck/公开类型、构建、headless、真实 DevTools 的顺序验证。最终三个场景均完整执行首次挂载和重入检查，首帧日志包含冷启动阶段。测试不手写或修补构建产物。

2026-11-13 专项验收：真实微信开发者工具 Stable `2.02.2609250`，三个作者场景、七个 DOM 检查点全部通过，运行日志无 warning、error、exception，项目及宿主正常清理。Issue 1330、1331 使用作者配置的基础库 `3.17.4`，Issue 1332 实际连接基础库为 `3.18.0`。同样三个场景的 headless 验证全部通过；simulator 的 Node、browser session 与 Chromium 属性警告回归通过。该结果为本 PR 的专项验收，不代表全仓全面 IDE 验收。

辅助验证包括格式化与外部脚本定位单测、编译及运行时首帧/异步 guard/abort/显式 null 回归，四个所属包的 typecheck 和公开类型检查，以及 scoped ESLint、Stylelint、suite manifest 和 DOM 清单检查。

新增首帧编译判断独立为 `compileVueFile/initialRender.ts`，属性诊断独立为 `componentInstance/propertyDiagnostics.ts`。首帧标记与字段筛选归属于组件定义入口，通过现有 setup 绑定与原生状态恢复规则交付，不扩展通用应用快照路径。既有注册 options 和 script rewrite 超过 300 行，本次仅在既有入口增加小型逻辑；大范围拆分会影响生命周期与 HMR，留在各自原拥有者中，避免扩展本次修复范围。

CI 扩展验证发现已生成模板可能包含宿主允许的重复属性。首帧包装只分析顶层声明边界，因此保留重复属性原文；无效元素边界仍然报错。零售 Web 模板和 Wot UI 构建纳入复验。组件专用逻辑移出最小应用路径后，原有 runtime 体积预算全部通过，未调整预算。

这些是用户可见行为修复，需要中文 change intent，包含 compiler、weapp-vite、wevu、constants、simulator，并联动 create-weapp-vite 和 constants 的所有公开直接消费者。使用 `fix` Conventional Commit，在一个 PR 中关闭三个 issue。
