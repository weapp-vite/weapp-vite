## 核心函数

### `createPinia()` {#createpinia}

<!-- api-reference-details -->

**类型签名：** `typeof import('wevu/store')['createPinia']`

**运行时说明：** 状态由 Wevu 响应式系统追踪，并随所属页面或组件的渲染批次同步；解构 state/getter 时必须使用 `storeToRefs()`。

**示例：** 见 [本组示例](/wevu/api/store#example-store-entry)。

- 类型入口：`StoreManager`
- 用途：推荐的 Store 管理器创建入口，以 Pinia 的 `createPinia()` 命名和主要用法为参照；需通过 `use(manager)`、`app.use(manager)` 安装，或显式传给 `useStore(manager)`。不会隐式激活。

### `createStore()` {#createstore}

<!-- api-reference-details -->

**类型签名：** `typeof import('wevu/store')['createStore']`

**运行时说明：** `createPinia()` 的同实现兼容别名，保留旧 API 名称且不新增弃用警告，既有应用无需仅为改名而修改；推荐通过 `createPinia()` 创建管理器。使用 `app.use(pinia)` 或 app.vue 的 `use(pinia)` 安装；也可显式 `useStore(pinia)`。

**示例：** 见 [本组示例](/wevu/api/store#example-store-entry)。

**Vue/Pinia 差异：** 使用 wevu 响应式，支持基础插件上下文；不提供 Web SSR、Pinia HMR 和 Vue Devtools。

### `defineStore()` {#definestore}

<!-- api-reference-details -->

**类型签名：** `typeof import('wevu/store')['defineStore']`

**运行时说明：** 状态由 Wevu 响应式系统追踪，并随所属页面或组件的渲染批次同步；解构 state/getter 时必须使用 `storeToRefs()`。

**Vue/Pinia 差异：** Store 对外自动解包 ref；`storeToRefs()` 仅提取响应式 state/getters 和插件属性，排除函数及普通属性，只读 getter 保持只读。

**示例：** 见 [本组示例](/wevu/api/store#example-store-entry)。

- 类型入口：`DefineStoreOptions`
- 用途：定义 store（setup 风格或 option 风格）。

### `storeToRefs()` {#storetorefs}

<!-- api-reference-details -->

**类型签名：** `typeof import('wevu/store')['storeToRefs']`

**运行时说明：** 状态由 Wevu 响应式系统追踪，并随所属页面或组件的渲染批次同步；解构 state/getter 时必须使用 `storeToRefs()`。

**Vue/Pinia 差异：** Store 对外自动解包 ref；`storeToRefs()` 仅提取响应式 state/getters 和插件属性，排除函数及普通属性，只读 getter 保持只读。

**示例：** 见 [本组示例](/wevu/api/store#example-store-entry)。

- 类型入口：`StoreToRefsResult`
- 用途：将 store 状态转换为 refs，避免解构丢失响应性。

### 本组示例 {#example-store-entry}

Setup Store 优先返回 Ref、computed 和 Action；状态解构使用 `storeToRefs()`。

```ts
import { computed, createPinia, defineStore, disposePinia, getActivePinia, ref, setActivePinia, storeToRefs } from 'wevu'

const manager = createPinia()
const useCounter = defineStore('counter', () => {
  const count = ref(0)
  const doubled = computed(() => count.value * 2)
  const increment = () => count.value += 1
  return { count, doubled, increment }
})

const counter = useCounter(manager)
const { count, doubled } = storeToRefs(counter)

setActivePinia(manager)
const activeManager = getActivePinia() // manager
// 应用或测试结束时释放整个 manager。
disposePinia(manager)
setActivePinia(undefined)
```
