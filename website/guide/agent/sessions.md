## 查看与恢复

```bash
weapp-agent sessions
weapp-agent resume SESSION_ID "继续处理构建失败"
```

终端在任务开始时显示会话 ID。日志使用版本化 JSONL，写入工具开始记录后才执行工具，完成后保存结果。

## 中断发生在执行过程中

如果命令已启动但结果尚未落盘，引擎无法凭日志判断它是否已经生效。这时返回 `action_required`，不自动重放。

先检查代码 diff、生成文件、运行中的进程以及外部系统状态，再明确确认：

```bash
weapp-agent resume SESSION_ID --acknowledge-interrupted "已核对当前状态，继续剩余工作"
```

此选项将未完成调用标记为结果未知，提醒模型重新检查；它不会再次执行原调用。

同一会话只允许一个写入进程。恢复时能处理末尾未完整写入的一行；其他日志损坏会报错。

## 上下文与上限

默认最多 40 个模型步骤，总运行超时 10 分钟。较长历史会压缩为有来源标识的摘要，同时保留最近的工具调用与结果配对。摘要不替代原始日志。

完整会话保留在本机。根据项目的数据留存要求管理和删除状态目录。
