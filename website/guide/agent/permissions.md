## 信任项目

首次运行时审阅项目脚本、模型配置与 MCP 服务。交互模式询问是否信任；自动化环境可以显式传入 `--trust`。

信任记录绑定项目绝对路径、配置和 `package.json` 内容。配置变化后旧记录失效。运行过程中脚本变化也会触发重新确认。

## 操作规则

| 操作 | 默认处理 |
| --- | --- |
| 读取普通项目文件 | 允许 |
| 在可信项目内创建或编辑文件 | 自动执行，检查冲突 |
| 执行可信配置中的验证命令 | 自动执行 |
| 任意 Shell | 每次展示具体命令并确认 |
| 内置微信运行时操作 | 在可信项目内，按明确工具名单执行 |
| 未知 MCP 工具、上传、发布 | 确认具体调用 |
| 文件越界、外部符号链接、敏感文件 | 文件工具拒绝 |

这是一套工具权限控制，不是操作系统沙箱。可信项目脚本和经批准的 Shell 仍以当前用户身份执行；请先审阅不熟悉的项目。

## 非交互执行

`--json` 禁止交互询问；未授权操作返回 `action_required`，退出码为 2。不要依赖自动化环境替你批准发布操作。

会话和信任记录默认位于用户本地状态目录，可使用 `WEAPP_AGENT_STATE_DIR` 指定其他目录。已知环境密钥与常见 token 格式会被脱敏，但这不替代对输入和源码内容的审阅。
