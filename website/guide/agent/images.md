## 添加图片

```bash
weapp-agent run "参考这个页面实现首页，保留项目组件体系" --image ./reference.png
```

支持 PNG、JPEG、WebP，每张图片最多 10 MB。图片通过模型的视觉输入发送，模型是否支持由所选 provider 和模型决定。

截图可以来自需求稿或你自己的页面。避免包含密钥、个人资料或与任务无关的信息。

## 验证视觉结果

参考图输入不等于视觉验证。使用微信开发者工具截图，对照布局、文字、交互状态和日志。需要基线比较时接入项目现有的截图对比命令；差异结果保留为独立证据。
