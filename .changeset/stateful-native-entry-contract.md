fix(hmr): 修复微信开发者工具重新执行原生页面入口时，热更新运行时能力缺失会先触发异常、无法回退 classic 的问题。在执行入口依赖和注册逻辑前检查运行时契约，并复用热更新客户端发起一次 classic 回退；保留正常业务异常的原有行为。

回退请求在完整同步期间仍会被处理；能力缺失或注册不兼容触发回退后，旧客户端停止交付与轮询，回退请求失败时保留首个错误并停止，避免继续执行 stateful 更新。

已有 stateful 产物时，将 IDE 配置交接延后到完整 classic 构建生成结束、原生写出之前，避免构建准备期间提前重载。交接保留用户配置变更，取消或生成失败时保留原产物和配置恢复责任。

classic 入口在仍保留旧 stateful 客户端的运行环境中等待完整重载，避免新入口读取旧模块缓存中的不兼容导出；重新加载后的 classic 行为和业务异常保持原有语义。

减少 npm 与平台 API 重写之间对无关依赖代码的重复解析；动态依赖配置仍按原有匹配顺序读取，保留更新后的执行行为与源码映射。
