为 `wevu/router` 增加显式启用的会话内滚动恢复：支持 WebView 页面、WebView/Skyline `scroll-view` 和自定义快照，默认按包含 query 的 `fullPath` 与容器 `id` 隔离位置。自动模式只在新建页面的路由、就绪与宿主提交完成后恢复，不覆盖原生返回页或保留 tab 的位置；异步业务内容可手动恢复，并通过活动性检查与清理 API 避免迟到写入。

编译器识别页面滚动适配器并启用所需页面事件；Web 与 headless 宿主补充带路由事件标识的阶段通知及共享能力契约，协调已有页面滚动恢复的执行权。重复切换当前唯一 tab 保持无操作，不新增历史项、制造路由事件或覆盖滚动快照。页面滚动观察器保留原有业务 hook 的优先级；宿主已发送实际滚动事件时，不再额外合成 API 通知或误通知导航后的页面。模拟器等待实际 renderer 提交，在支持的显式尺寸范围内裁剪滚动位置，并统一预览与测试节点的原生点击传播；途中销毁或重建组件不改变本次交互的原始归属。工作台替换项目时关闭旧会话，阻止旧提交确认新预览；初始化或导入失败时保留当前可用预览。

修正 `Component` 页面滚动方法的原生注册，确保真实页面滚动进入观察器；对原生同路径 `reLaunch` 的空完成 ID，按已确认新页面的宿主身份严格关联，不接受迟到的旧页面通知。

同步滚动恢复的接入示例、公开类型、SDK/渲染器边界和会话清理说明，并联动更新脚手架。快照只保留在当前运行会话的内存中，不跨冷启动持久化。
