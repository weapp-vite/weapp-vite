整合 Dashboard 包体诊断、对象关联与证据检查，提供可选 `--ui-host hub` 工作台及受限 MCP 调查入口。

- 包、产物、模块通过统一对象工作台关联，紧凑滚动列表保留完整搜索与当前对象定位；选择只滚动相关列，不补回过滤对象或反复打断手动浏览。页签、筛选及对象选择原子更新，保留无关查询参数。
- 统一构建摘要和诊断工作台，提供问题索引、同尺度体积对照、模块来源与复验条件；评分及完整指标按需展开，保留全局侧栏与窄屏导航。区分预算、风险、增长/重复线索及缺测，不把最大文件自动当问题或估算当保证收益。
- 历史大面板收敛为对照基线选择，移除趋势预测，手动跟进清单移至高级评审；保留随证据变化失效的只读处理计划。
- 只读 AI 上下文与处理计划绑定报告 revision，刷新、重连、基线或选中对象变化即失效；显式源码/产物下钻不受旧预算筛选干扰，复制失败保留手动路径，交接自身不启动 Agent 或授权执行。
- standalone 自动开放同端口本机只读 DevFrame MCP，无需配置令牌，与页面共用 RPC、分页快照和 revision，核验真实 loopback 对端与规范 Origin，随监听/重启/关闭维护实例记录；保留浏览器 OTP、已有 MCP/REST 及 IDE 入口。
- 调查提交、外部 Agent 领取/提案、浏览器精确授权、回执及更新报告复验共用受限 Dashboard MCP，不提供任意写文件或执行命令。Hub 复用既有报告与连接，保留默认独立模式，不开放聚合 MCP 或实例发现。
- MCP、页面与 Markdown 共用摘要预算、包/产物/模块检索、重复分析、构建比较、事件筛选及受限文件片段读取；复用实际文件去重、runtime 上界、分包覆盖和缺测判定，保留零限额、估算、独立分包隔离与事件窗口丢弃语义。
- 依赖图按可见范围展示关系及统计，节点详情提供完整路径、导入/被引用/包内产物跳转；悬停/选中聚焦一跳与单条箭头，按节点半径裁剪连线，重叠时隐藏，修复 SVG 尺寸反复增长和悬浮闪烁。
- 对象关系支持沿包到模块的选中流动指示，尊重减少动态效果设置；统一微信绿品牌、亮暗主题文字对比度、焦点、工具栏提示与触屏入口。长路径、窄屏表格和键盘滚动保留可读性，官方图标内联加载，隔离打包不依赖外部图标服务。
