perf(weapp-vite): 修复多页面构建中 fallback 页面逐个扫描全部已发布入口导致的平方级路径处理开销。每轮同步建立输出路径索引，并在生成逻辑入口及登记各角色依赖时复用同一同步操作的真实路径解析；下一轮重新读取输出映射和符号链接目标，保留增量与完整构建的一致性。

移除 sidecar 协议中同一 owner/source 的重复路径解析，以及虚拟入口解析后的重复规范化。插件仅判断请求类型时复用协议校验，不查询文件系统；图登记仍重新解析文件身份，保持符号链接改向与外部依赖隔离。自动检测到 Tailwind 但尚未发现 CSS 入口时，避免为每个普通模块查询真实路径，保留首次样式导入后的正常激活。

仅在微信原生动态导入实际需要转换时解析分包归属，避免普通模块与其他平台执行无效路径查询。

登记入口和转换依赖时，仅在单次同步操作内复用重复源码身份的真实路径解析；下一次登记重新读取符号链接目标，输入集合抛错后也及时释放复用范围。没有转换依赖时直接返回空集合，避免每个普通模块执行无效的真实路径查询。

完整和局部输出图刷新在单次同步遍历内复用逻辑入口的真实路径解析，避免 facade 和 moduleIds 重复查询同一文件；下一轮和异常恢复均重新解析，不跨构建保留缓存。
