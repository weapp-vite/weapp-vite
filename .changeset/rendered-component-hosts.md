保留组件渲染宿主的 ID、类名和绑定属性，使 headless 测试能查询真实组件边界及内部节点；同步 browser 渲染器，并支持通用组件和组件标签选择器。

修复 slot 投影绕过条件分支选择的问题，确保关闭后重新打开的默认和具名 slot 反映最新父级状态。

支持页面及组件的 WXML 模板导入，保持导入文件的私有依赖作用域；防止 Component 页面配置覆盖宿主保存的导航参数。

支持独立作用域的 WXS 外部与内联模块、对象 WXML 循环和普通属性选择器，使平台标签、API 执行结果和导航链接的渲染与真实微信 IDE 保持一致。

新增启动前 session 订阅钩子，便于完整采集 App 和首屏初始化日志；启动失败时自动释放 session。

渲染时仅卸载当前页面消失的组件，保留隐藏 tab 和导航栈页面的组件实例，使返回页面后的状态与 show/hide 生命周期连续。

补齐测试 page handle 的 setData 接口和原生组件的 __data__ 描述符，使状态更新及第三方组件 template ref 的检查可在两种 provider 中复用。
